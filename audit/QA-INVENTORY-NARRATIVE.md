# Seven-part narrative QA inventory

## Requirements and intended signoff

- Preserve the pre-rebuild GitHub version and the prior preview. Check immutable Git refs, durable source archives, and the in-site previous-version link.
- Report chapters follow the approved seven-part order. Check DOM order, chapter rail, mobile selector and deck chapter sequence.
- Default reading path excludes optional depth; every rabbit hole remains reachable. Check native disclosure open/close, all-open mode, all-closed mode and direct links into closed depth.
- Latest edition notes only. Check live report and latest-update page for old update plaques. Historical metric observation dates must remain.
- Every repeated editorial figure has one evidence record. Compare rendered report, slides, mouseovers and evidence drawers with the registry; inspect a matrix of monetary, percentage, forecast, historical and transaction records.
- Keep healthcare money river and patient loop, robotics river, industrial river, service map, agent stack and portfolio explorer. Check real click-driven detail states, controls, reset, filters and mobile drawers.
- Preserve cinematic opening, presentation mode, slide routes, keyboard, previous/next controls and report links. No deferred bear-case slide.
- No missing local files, duplicate IDs, runtime exceptions, contradictory capex totals or unqualified stale financial benchmarks.

## Visual checks

- Desktop 1440 × 1000; mobile 375 × 812; short desktop 1280 × 720; same live page resize desktop → mobile → desktop.
- Inspect cover, each of seven chapter openings, dense expanded service map, all three rivers and a source drawer.
- Inspect every slide at desktop and mobile. Slides may scroll vertically in small viewports, but required navigation must remain available and content must not be horizontally clipped.
- Inspect labels, type hierarchy, DVC colors, square panels and source qualifiers at the narrowest viewport.
- Source links must open the expected destination; full URL plus manual-copy fallback remains available.

## Off-happy-path checks

- Deep-link directly into a closed healthcare or industrial explorer, then return to reading mode.
- Remove every issuer from the capex comparison, then restore all issuers; check zero and aggregate states.
- Open evidence, use Escape, then verify focus returns and deck navigation resumes.
- Enter the deck at a middle hash and reload. Check non-overlapping slide content and correct counter.
- Reduced-motion/no-animation state must retain meaningful visible content.
